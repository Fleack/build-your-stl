# Warm-up: `a + b`

Implement [`bys::add`](include/bys/add.hpp) to return the sum of two integers.

Build and run the tests from the repository root. The tests will fail with the starter code and pass once the sum is implemented correctly.

```sh
cmake -S . -B out/add
cmake --build out/add --target add_tests
./out/add/exercises/warmup/add/add_tests
```

When the test summary shows `0 failed`, move on to [`bys::find`](../../algorithms/find/README.md).
