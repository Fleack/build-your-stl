# `bys::vector`

Реализуйте основной шаблон `vector` из C++20 в [include/bys/vector.hpp](include/bys/vector.hpp). Специализация `vector<bool>` с битовым хранением выходит за рамки задания.

- [`std::vector` на cppreference](https://en.cppreference.com/cpp/container/vector)
- [`std::vector` в проекте стандарта C++20](https://timsong-cpp.github.io/cppwp/n4861/vector)

**Вход.** Тип элемента `T`, необязательный тип аллокатора и начальные элементы, заданные количеством, количеством и значением, диапазоном итераторов или списком инициализации. Вектор также можно создать пустым, скопировать или переместить из другого вектора.

**Результат.** Контейнер переменного размера, который владеет непрерывной последовательностью. Поддержите типы, вывод параметров шаблона, создание, присваивание, доступ к элементам, обход, управление ёмкостью, изменение содержимого, работу с аллокаторами и сравнения по C++20. Добавьте свободные функции `bys::swap`, `bys::erase` и `bys::erase_if`.

## Сборка и запуск тестов

После реализации `bys::vector` выполните команды из корня проекта.

```sh
cmake -S . -B out/vector
cmake --build out/vector --target vector_tests
./out/vector/exercises/containers/vector/vector_tests
```
